# Campus Quota for Windows

Campus Quota for Windows and macOS now share one repository. Clone [ronilborah/lan-limit](https://github.com/ronilborah/lan-limit), open the cloned folder in File Explorer and double-click **Campus Quota.exe**. On a Mac, double-click **Campus Quota.app**.

For Windows setup, tray controls and troubleshooting, see the [Windows guide](https://github.com/ronilborah/lan-limit/blob/main/Windows/README.md). Please file issues and pull requests in the unified repository.

This repository preserves the original Windows source and commit history.
